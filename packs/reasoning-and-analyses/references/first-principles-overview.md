# First Principles Thinking — Overview

Coined by Aristotle, popularized in modern times by Elon Musk. The pattern that every skill in this pack is a tool for.

## The 3-step core

1. **Identify assumptions.** What are we taking for granted? Surface everything you believe is true about the problem.
2. **Break down to first principles.** What do we know for sure? Discard everything that is assumption, convention, or analogy. Keep only what is true and necessary.
3. **Rebuild from scratch.** Using only what is true and necessary, construct the solution upward.

## When to apply first principles at all

Read `analogy-vs-first-principle-matrix/SKILL.md` first. Not every problem needs first-principles reasoning — many problems already have proven analog solutions, and analogy is faster. Use first principles when:

- The analogous solution itself is failing.
- The stakes are high and the novelty is high.
- "We've always done it this way" is the only argument being made for the current approach.

## Anti-pattern

Treating first principles as a hairshirt. The point is to discard *unjustified* assumptions, not all assumptions. If an assumption is true (a real physical constraint, a real legal requirement), keep it. The pattern widens the solution space by removing fog, not by ignoring reality.
